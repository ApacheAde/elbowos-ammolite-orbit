# Ammolite Orbit

Full-colour Python 3 neon orbital-hop arcade for [ElbowOS](https://x.com/ElbowOS).

Ride four concentric iridescent rails around a spinning ammolite core.
Hop inward / outward to scoop colour flakes and dodge dark meteorites.

W / S or Up / Down hop orbits. R resets.

## Play

```
pip install -r requirements.txt
python3 ammolite_orbit.py --play
```

## Record a 9:16 reel

```
python3 ammolite_orbit.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
